# Demo sandbox

Open `/demo/?demo=1` or `/?demo=1` to start the sample.

The sample is a ready reminder after a 20-minute project-brief reading session. Select **Start distance break** after reaching a stopping point to open a 20-second distance break, then finish it. The banner stays visible while the sample is active.

All sample writes use the `demo:pacer` localStorage key. The demo never reads or writes extension storage or non-demo website keys. **Reset demo** replaces only that key with the ready sample. **Start for real** removes only that key and takes the visitor to installation.
